JDS6600 Controller — Windows 7 legacy build

This build is intended for Windows 7 x64.

Important:
- Install Microsoft update KB2533623 before launching the program.
- Prefer starting the program via JDS6600Controller-win7-legacy-launch.cmd.
  The launcher checks for KB2533623 and shows a hint if it appears to be missing.
- If you start the .exe directly and Windows shows a DLL/startup error, install KB2533623 and try again.
